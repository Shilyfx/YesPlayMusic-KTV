### 入口和布局

- 右下角用 Folia 图 2 同类的线性调节图标，点击展开，再次点击、点面板外、按 Esc 或关闭按钮收起。

歌词和背景独立选择：换歌词不重置背景，换背景不重新加载歌词。保留上游兼容规则，例如静止不画背景、浮名自身的几何图形开关。

图片资源不能把主屏 `blob:` 地址发给副屏，也不能每次心跳传 Base64。主屏共享素材采用有界上传、内容哈希去重、资源 ID 和缓存；副屏本屏自定义素材可以存入本浏览器 IndexedDB。完整外观配置走 generation／revision 缓存，图片走独立资源路径，保留当前心跳大小限制和单一轮询 owner。

“透明播放背景”在网页中表示透出 KTV 背景层；操作系统桌面级透明窗口属于 Electron 能力，不能把两者混为一谈。嵌入背景遇到目标网站禁止 iframe、网络失败或不适合透明显示时，需要有实际状态和可恢复入口。

采用太阳／月亮图标和滑动选中块，保留自动跟随设置。面板展开采用原版 0.92→1 缩放与透明度动画；控件响应 120ms、短位移 220ms、展开 300ms，缓动参考 `KIT_EASE`。

Folia 的平滑体验分布在面板动效、背景颜色插值、图像交叉渐变和样式切换层，不是复制一个主题切换函数就能获得。原版样式柔焦切换参数为退出 360ms、进入延迟 80ms／时长 520ms；这是样式／背景切换，不能误当成所有明暗切换的统一时长。

我们的实施重点：

- 把 Folia token 映射到现有 `--ktv-*`，按背景色、文字、边线和选中块分别过渡；不使用全页 `transition: all`。
- 主题变化从 `KaraokePvScene.vue` 当前全量 `queueBuild` 路径拆出，核对每个原版运行时的实际更新能力。上游已有 `swapSong`／`setTuning` 等接口，但并非所有引擎都有可直接调用的 `setTheme`。
- 能原位更新的保持运行时；需要重绘的保留旧画面直到新帧准备好，再有限交叉过渡。不得先清空画布再等待新引擎。
- 主题切换不改播放状态、歌曲位置、歌词偏移或已加载歌词文档；连续快速切换只采用最新一代结果。
- 减少动态效果时关闭过渡，暂停／页面隐藏时不新增持续动画。

## 7. 架构方案建议

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| A：Vue 控制板＋Folia 原版渲染适配层（推荐） | 保持现有播放器、Vuex、主副屏权限与偏好；界面按原版 token 重建，保留原版视觉算法 | 需要明确的跨渲染层契约，逐项映射参数与生命周期 |
| B：连同 Folia React 控制板一起嵌入，再接 LumaSing 播放桥 | 面板组件复用程度更高 | 要剥离 Folia 的播放器、store、账号、资源和同步依赖；与当前 Vue 页面联动及两套状态所有权更复杂 |

建议 A。已经在项目依赖中的 React／ReactDOM／Framer Motion 可以承载需要 React 的原版渲染器；新增 Three.js、React Three Fiber、TWGL 等依赖前先确定最小闭包。原版 `import.meta.glob` 注册方式不能原样塞进 Webpack 4，使用显式轻量清单和按模式懒加载。不得把整个 Folia 播放器、第二路音频或独立播放进度一起搬进来。

拟新增／扩展模块：

- `KaraokeControlPanel.vue`：统一面板，复用主屏／副屏能力描述。
- `KaraokeControlToggle.vue`：右下角入口、展开／关闭及全屏层级。
- `visualConfig.js`：模式／背景／主题／参数的校验、默认值和持久化迁移。
- `folia/registry` 与 `folia/renderHost`：上游模式与背景清单、懒加载和运行时生命周期。
- `folia/bridge`：单一时间轴、歌词文档、主题、资源、可用的音频特征适配。
- 服务端外观快照／共享素材模块：只传 revision 和资源引用，保留现有单一 exchange／display owner。

开发时先对原版依赖闭包列清单，保留来源清单和最小补丁；持续提供对应源码下载。
