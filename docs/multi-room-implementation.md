- [x] Mac 与 Docker 源码接入，以及九张歌手静态头像的构建复制。
- [x] 本机双主机联调：验证两个真实主机服务的隔离、点歌、头像和关房失效；这不等同于 Mac 实机或 Docker 容器测试。
